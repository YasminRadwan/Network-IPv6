# IPv6 Configuration – Cisco Packet Tracer

## Overview
This project demonstrates the implementation of IPv6 addressing and routing on Cisco
devices. It covers static IPv6 configuration, IPv6 routing protocols, and interface
assignments to enable modern IP communication in a network environment.

The lab emphasizes IPv6 fundamentals and practical hands-on configuration skills.

---

## Tools & Technologies
- Cisco Packet Tracer
- Cisco IOS
- IPv6 Addressing
- IPv6 Routing (Static / RIPng / OSPFv3)
- TCP/IP

---

## Configuration Summary
The configuration includes:

- Assigning IPv6 addresses to interfaces
- Enabling IPv6 routing on routers
- Configuring static IPv6 routes
- Configuring IPv6 routing protocols (RIPng / OSPFv3)
- Verifying connectivity using IPv6 ping and routing commands

---

## Key Concepts Covered
- IPv6 address types (Global, Link-local, Unique Local)
- IPv6 interface configuration
- Enabling IPv6 routing
- IPv6 static routing and dynamic routing
- Verification of IPv6 connectivity

---

## Verification
Use the following commands to verify configurations:

- `show ipv6 interface brief` – Check interface IPv6 addresses  
- `ping <ipv6_address>` – Test connectivity  
- `show running-config` – Review full configuration  
- `show ipv6 route` – Verify IPv6 routing table  
- `show ipv6 neighbors` – Check neighbor entries

## How to Use
1. Open the `.pkt` file in Cisco Packet Tracer  
2. Review IPv6 addresses and interface configuration  
3. Review routing configuration (Static or Dynamic)  
4. Test connectivity using `ping` with IPv6 addresses  
5. Verify routing table and neighbor information
